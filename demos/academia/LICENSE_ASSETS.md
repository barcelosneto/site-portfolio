# Licença e Origem dos Recursos Visuais (`LICENSE_ASSETS.md`)

Todos os recursos visuais, ícones e ilustrações presentes na pasta `assets/img/` e na raiz (`favicon.svg`) foram **criados autoralmente em código SVG vetorial exclusivo para este projeto**, não dependendo de bancos de imagens externos, URLs de terceiros sujeitas a expiração ou licenças restritivas.

## Tipografia

O projeto utiliza pilha de fontes nativas de alta performance (`"Inter", -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, sans-serif`), eliminando requisições bloqueantes externas, garantindo zero transferência de dados para terceiros (LGPD) e evitando Cumulative Layout Shift (CLS).
